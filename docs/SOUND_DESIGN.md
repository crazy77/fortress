# Fortress 사운드 디자인 문서

## 1. 사운드 철학

> **Web Audio API 프로시저럴 사운드 -- 에셋 없이 분위기 있는 전장을 구현한다.**

Fortress의 모든 사운드는 `AudioContext`의 오실레이터, 노이즈 버퍼, 필터를 조합하여 실시간 생성된다.
오디오 파일(mp3, wav 등)을 일절 사용하지 않으며, 코드만으로 탱크별 고유 사운드 아이덴티티를 표현한다.

### 설계 원칙

| 원칙 | 설명 |
|------|------|
| Zero-asset | 외부 오디오 에셋 의존성 없음 |
| Character-driven | 6종 탱크 각각 고유한 발사/비행/폭발/피격/이동음 |
| Contextual | 게임 상태(타이틀/전투/긴박/승리/패배)에 따른 BGM 전환 |
| Non-intrusive | 뮤트 토글 지원, 볼륨 절제 (마스터 게인 0.12) |

### 오디오 시스템 구성

| 시스템 | 클래스 | 역할 |
|--------|--------|------|
| SFX | `AudioSystem` | 효과음 (발사, 폭발, 피격, 이동, UI) |
| BGM | `BGMSystem` | 배경 음악 (5모드 코드 진행) |

## 2. 탱크별 발사음 특성

### 캐논 -- "듬직한 병사"

> 따뜻하고 묵직한 포격음

| 레이어 | 오실레이터 | 주파수 | 볼륨 | 지속시간 |
|--------|-----------|--------|------|----------|
| 메인 포격 | sawtooth | 220Hz → 70Hz | 0.28 | 180ms |
| 서브베이스 펀치 | sine | 80Hz → 30Hz | 0.20 | 120ms |
| 노이즈 파열 | noise burst | -- | 0.18 | 60ms |

### 호버 -- "날렵한 요정"

> 가볍고 영롱한 에너지 발사음

| 레이어 | 오실레이터 | 주파수 | 볼륨 | 지속시간 |
|--------|-----------|--------|------|----------|
| 에너지 축적 | sine | 400Hz → 800Hz | 0.08 | 50ms |
| 메인 발사 | triangle | 700Hz → 180Hz | 0.18 | 100ms |
| 반짝이 고음 | sine | 1200Hz → 600Hz | 0.05 | 50ms |
| 노이즈 파열 | noise burst | -- | 0.08 | 80ms |

### 중전차 -- "무뚝뚝한 거인"

> 지축을 흔드는 초저음

| 레이어 | 오실레이터 | 주파수 | 볼륨 | 지속시간 |
|--------|-----------|--------|------|----------|
| 초저음 서브베이스 | sine | 50Hz → 20Hz | 0.35 | 350ms |
| 중음 포격 | sawtooth | 120Hz → 35Hz | 0.30 | 300ms |
| 필터드 노이즈 | filtered noise | LP 400Hz → 60Hz | 0.15 | 350ms |

### 미사일 -- "냉정한 저격수"

> 날카로운 제트 점화

| 레이어 | 오실레이터 | 주파수 | 볼륨 | 지속시간 |
|--------|-----------|--------|------|----------|
| 점화 클릭 | square | 1500Hz | 0.08 | 20ms |
| 제트 점화 | sine | 300Hz → 900Hz → 400Hz | 0.20 | 330ms |
| 고압 노이즈 | filtered noise | LP 2000Hz → 400Hz | 0.12 | 250ms |

### 레이저 -- "신비한 마법사"

> 충전 차지업 + 고주파 zap 해제

| 레이어 | 오실레이터 | 주파수 | 볼륨 | 지속시간 |
|--------|-----------|--------|------|----------|
| 차지업 | sine | 200Hz → 1800Hz | 0.06→0.12 | 120ms |
| 메인 빔 zap | square | 1400Hz → 400Hz | 0.14 | 120ms |
| 크리스탈 하모닉 | sine | 2800Hz → 800Hz | 0.06 | 70ms |

### 카타펄트 -- "장난꾸러기 투석기"

> 나무 삐걱 + 투석 임팩트

| 레이어 | 오실레이터 | 주파수 | 볼륨 | 지속시간 |
|--------|-----------|--------|------|----------|
| 나무 삐걱 (크릭) | sawtooth | 100Hz → 140Hz → 90Hz | 0.15 | 120ms |
| 투석 임팩트 | sine | 150Hz → 50Hz | 0.25 | 140ms |
| 돌 날아가는 노이즈 | noise burst | -- | 0.15 | 80ms |

## 3. 비행음 (궤적 사운드)

포탄 비행 중 속도에 따른 실시간 사운드가 재생된다.

| 탱크 | 파형 | 주파수 범위 | 볼륨 | 지속시간 | 특성 |
|------|------|------------|------|----------|------|
| 캐논 | sine | 200~500Hz | 0.05 | 50ms | 클래식 포탄 휘파람 |
| 호버 | triangle | 550+Hz | 0.035 | 50ms | 영롱한 에너지 통과음 |
| 중전차 | sawtooth | 80~250Hz | 0.04 | 60ms | 무거운 저음 윙윙 |
| 미사일 | sawtooth | 350+Hz | 0.04 | 40ms | 제트 엔진 지속음 |
| 레이저 | square | 900+Hz | 0.025 | 40ms | 고주파 에너지 험 |
| 카타펄트 | sine | 150~350Hz | 0.04 | 60ms | 바위 날아가는 바람소리 |

## 4. 폭발음

폭발음은 **노이즈 버퍼 + 로우패스 필터 + 서브베이스 펀치**로 구성된다.
강도(intensity)와 탱크 스타일에 따라 필터 특성이 달라진다.

| 탱크 | 필터 시작 | 필터 종료 | 서브베이스 | 특성 |
|------|-----------|-----------|-----------|------|
| 캐논 | 600~900Hz | 60Hz | 50Hz | 표준 폭발 |
| 호버 | 1200Hz | 100Hz | 50Hz | 중고음 에너지 파열 |
| 중전차 | 400Hz | 40Hz | 30Hz | 극저음 + 긴 잔향 |
| 미사일 | 600~900Hz | 60Hz | 50Hz | 표준 (캐논과 유사) |
| 레이저 | 2000Hz | 200Hz | 50Hz | 높고 날카로운 크랙 |
| 카타펄트 | 500Hz | 50Hz | 40Hz | 둔탁한 임팩트 |

## 8. BGM 5모드

### 코드 진행 체계

BGM은 **코드 진행 + 베이스 + 멜로디 + 퍼커션** 4레이어로 구성된다.
기본 음정은 C3 (MIDI 48) 기준 자연단음계(natural minor)를 사용한다.

| 모드 | BPM | 코드 진행 | 패드 파형 | 멜로디 파형 | 퍼커션 |
|------|-----|-----------|-----------|-------------|--------|
| **title** | 80 | i → iv → III → v | sine | sine (펜타토닉) | 없음 |
| **gameplay** | 100 | i → v → iv → III | triangle | sine (펜타토닉) | 킥+하이햇 |
| **intense** | 140 | i → dim → iv → V | triangle | square (펜타토닉) | 킥+하이햇 (강세) |
| **victory** | 120 | I → IV → V → I (메이저!) | triangle | sine (메이저 스케일) | 없음 |
| **defeat** | 60 | i → iv → iii dim → i | triangle | 없음 (확률적 비활성) | 없음 |

### 레이어 상세

#### 패드 (Pad)

- 코드 교체마다 3개 오실레이터가 코드 음을 지속
- 볼륨: title 0.08, intense 0.06, 기타 0.05
- 지속시간: intense 0.8초, 기타 1.6초
- 페이드인 0.1초 → 지속 → 페이드아웃

#### 베이스 (Bass)

- 코드의 근음(root)을 한 옥타브 아래에서 재생
- 매 2비트마다 재생
- sine 파형, 볼륨 0.07 (intense 시 0.1)

#### 멜로디 (Melody)

- 60% 확률로 비트마다 랜덤 음 선택
- defeat 모드에서는 비활성
- 펜타토닉 스케일 [0,3,5,7,10] 사용 (victory 시 메이저 [0,4,7,11,12])
- 짧은 스타카토 (150~350ms)

#### 퍼커션 (Percussion)

- gameplay/intense 모드에서만 활성
- **킥**: sine 120→30Hz, 매 2비트 (intense 볼륨 0.12, 기본 0.06)
- **하이햇**: 화이트 노이즈 + HP 필터 8000Hz, 매 비트 (30ms, 볼륨 0.02)

### 마스터 볼륨

| 항목 | 값 |
|------|-----|
| 마스터 게인 | 0.12 |
| 뮤트 지원 | O (SFX/BGM 독립 토글) |
| AudioContext | 필요 시 생성 (lazy init) |
| suspended 복구 | 자동 resume() |

## 9. 진동 피드백

모바일 디바이스에서 `navigator.vibrate` API를 통한 햅틱 피드백을 지원한다.

```typescript
export function vibrate(pattern: number | number[]): void {
  if (navigator.vibrate) {
    navigator.vibrate(pattern);
  }
}
```
