# Fortress 모바일 웹 포트리스 게임 - PRD

## 1. 현재 상태

### 구현 완료
- 2인 로컬 턴제 포병 게임플레이
- 절차적 지형 생성 + 파괴 가능 지형 (RenderTexture + AlphaMap)
- 슬링샷 드래그 조준 + 파워 게이지 + 드래그 인디케이터
- 바람 시스템 (매 턴 랜덤)
- 탱크 좌우 이동 + 지형 경사 추종 + 기울기 반영 발사
- 폭발 파티클, 카메라 셰이크/팔로우
- HP 시스템 (직격/스플래시/자해)
- 낙사 (지형 파괴 시 즉사)
- 게임 오버 + 재시작
- 모바일 터치 컨트롤

### 기술 스택
- Phaser 3 + TypeScript + Vite + Bun + Biome
- 에셋 제로 (프로시저럴 렌더링), 오디오 없음

## 6. 핵심 설계 원칙

1. **에셋 제로 유지** — 프로시저럴 렌더링 + Web Audio. 로딩 시간 제로.
2. **기존 아키텍처 존중** — Scene 분리, 이벤트 통신, TurnState 패턴 따라 확장.
3. **모바일 퍼스트** — 터치 영역 44px 이상, 배터리/성능 고려, Haptic 활용.
4. **점진적 복잡도** — 첫 판에서 즐길 수 있되, 숙련될수록 깊이 드러남.
5. **Solo Dev 현실성** — 각 항목 1~5일. XL은 Phase 2로. 고임팩트 S/M 우선.

## 7. 기술 참고

### 프로시저럴 사운드 (A-01)
```
발사음: OscillatorNode(sawtooth, 200→80Hz, 0.15s) + noise burst(0.05s)
폭발음: white noise → BiquadFilter(lowpass, 800→100Hz, 0.4s decay)
피격음: OscillatorNode(square, 600Hz, 0.05s) → 급속 감쇠
```

### AI 설계 (G-01)
```
목표 각도 = atan((v² ± √(v⁴ - g(gx² + 2yv²))) / (gx))
+ 난이도별 가우시안 노이즈 (Easy ±15°, Normal ±8°, Hard ±3°)
```

### 무기 데이터 구조 (M-02)
```typescript
interface WeaponDef {
  name: string;
  explosionRadius: number;
  directDamage: number;
  splashDamage: number;
  splashRadius: number;
  projectileCount: number;
  spreadAngle: number;
  ammo: number; // -1 = 무제한
}
```
