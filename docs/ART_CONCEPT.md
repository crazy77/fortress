# Fortress Battle Arena - 아트 컨셉 문서

## 1. 아트 방향성
- 프로시저럴 2D (에셋 제로, Canvas 2D + Phaser Graphics API)
- "귀여우면서 강력한" (Cute & Powerful)

## 2. 컬러 팔레트
패널: BG 0x0a0e17, Border 0x2a3a5c
P1: 빨강 0xe74c3c / 밝은빨강 0xff6b6b
P2: 파랑 0x3498db / 밝은파랑 0x74b9ff
골드: 0xf1c40f, 액센트: 0x00b4d8
HP: 초록→노랑→빨강 (0x2ecc71/0xf39c12/0xe74c3c)

## 3. 탱크 캐릭터 디자인 (6종)

### 캐논 "듬직한 병사" (빨강 0xc0392b)
- 둥근 차체, 원형 포탑, 노란 헤드라이트 "눈" 2개 (하나 약간 큼)
- 안테나 + 빨간 깃발, 황금 줄무늬, 둥근 트랙 커버

### 호버 "날렵한 요정" (보라 0x8e44ad)
- 날렵한 다이아몬드 실루엣, 트랙 없음 (5겹 시안 호버 글로우)
- 시안 바이저 라인, 양쪽 날개 핀, 에너지 안테나

### 중전차 "무뚝뚝한 거인" (초록 0x27ae60)
- 초광폭 2중 장갑, 5바퀴 트랙, 사각 포탑 + 4리벳
- 분노의 사각 헤드라이트, 노랑/검정 경고 스트라이프, 배기관 2개

### 미사일 "냉정한 저격수" (남색 0x2c3e50)
- 각진 쐐기형 차체, 미사일 런처 박스 (4개 발사관)
- 빨간 타겟 센서, 레이더 디시, 빨간 줄무늬, 십자선

### 레이저 "신비한 마법사" (청록 0x00bcd4)
- 우아한 곡선 차체, 반중력 스키드 (3겹 시안 글로우)
- 에너지 링 2겹, 크리스탈 다이아몬드 터렛, 부유 입자 4개

### 카타펄트 "장난꾸러기 투석기" (갈색 0x8d6e63)
- 나무 질감, 6개 바큇살 나무 바퀴, 밧줄 장식
- 귀여운 얼굴 (눈 2개 + 미소 곡선), 오렌지 깃발

## 4. 손상 표현 (4단계)

| 단계 | HP | 시각 효과 |
|------|-----|----------|
| normal | 100~75% | 깨끗한 원래 색상 |
| light | 75~50% | 찰과상 1줄 |
| damaged | 50~25% | 크랙 + 검은 스코치 + 색상 20% 어두움 |
| critical | 25~0% | 불꽃 + 연기 + 색상 40% 검붉게 |
| destroyed | 0% | 회색 + 부서진 포신 + 연기 파티클 |

## 5. 애니메이션
- 대기: 상하 2px 숨쉬기 + 탱크별 고유동작 (호버=부유, 중전차=진동, 레이저=맥동, 카타펄트=흔들림)
- 발사: 포신 후퇴(4~8px, Back.easeOut) + 차체 밀림(Elastic) + 탱크별 머즐 플래시
- 피격: 좌우 흔들림(데미지 비례) + 스퀴시 + 빨간 틴트 + 스파크

## 6. 포탄 디자인

| 탱크 | 포탄 | 연기색 |
|------|------|--------|
| 캐논 | 철 폭탄 + 도화선 불꽃 | 회색 0x888888 |
| 중전차 | 철갑탄 + 구리밴드 | 짙은회색 0x666666 |
| 미사일 | 유도미사일 + 추진불꽃 + 날개 | 주황 0xff8a65 |
| 레이저 | 다층 글로우 구체 + 렌즈플레어 | 시안 0x80deea |
| 호버 | 플라즈마 삼각 + 에너지 꼬리 | 보라 0xce93d8 |
| 카타펄트 | 이끼 낀 바위 | 갈색 0x8d6e63 |

## 7. 환경 아트
- 하늘: 50단계 그라데이션, 태양/달, 별 150개, 구름 10개
- 지형: 7단계 렌더링 (암석→토양→표면→하이라이트→그림자→노이즈→디테일)
- 날씨: 비/눈/모래폭풍/화산재/반딧불이/낙엽 (맵별 배정)
- 물: 3겹 파도 + 거품 (군도 맵)

## 8. UI 디자인
- 패널: 드롭쉐도우 + 유리 하이라이트 + 반투명 배경(0.88)
- HUD: 상단(HP×2 + 타이머 + 바람) / 하단(무기8 + 연료 + 인벤토리)
- 미니맵: 채운 지형 + 글로우 탱크 + 카메라 뷰
