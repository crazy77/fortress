# Fortress 아트 컨셉 문서

## 1. 아트 방향성

### 프로시저럴 2D, "Cute & Powerful"

Fortress의 비주얼은 **에셋 없이 순수 코드로 생성되는 프로시저럴 2D** 방식을 채택한다.
모든 탱크, 포탄, 지형, 이펙트가 `Phaser.GameObjects.Graphics` API로 실시간 렌더링된다.

**핵심 원칙**:
- 작고 귀여운 외형이지만 전투는 강력하고 박진감 넘치게
- 탱크마다 고유한 성격과 시각 아이덴티티
- 손상 상태가 외형에 즉각 반영 (4단계)
- 단순한 도형 조합으로 읽기 쉬운 실루엣

### 렌더링 해상도

| 항목 | 값 |
|------|-----|
| 월드 너비 | 2400px |
| 뷰포트 너비 | 1280px |
| 뷰포트 높이 | 720px |
| 플레이 영역 높이 | 640px |
| UI 바 높이 | 80px |
| 하늘 여유 | 300px |

## 4. 손상 표현 (5단계)

탱크는 HP 비율에 따라 외형이 실시간으로 변화한다.

| 상태 | HP 범위 | 시각 효과 |
|------|---------|-----------|
| **normal** | 76~100% | 원래 색상 그대로, 깨끗한 상태 |
| **light** | 51~75% | 원래 색상 + 작은 찰과상 (회색 스크래치 라인) |
| **damaged** | 26~50% | 어두운 색조 (20% 블렌딩) + 복수의 손상 마크 |
| **critical** | 1~25% | 검붉은 색조 (40% 블렌딩) + 손상 마크 + 연기/불꽃 이펙트 |
| **destroyed** | 0% | 회색 (`#444444`/`#333333`) + 파괴 오버레이 + 파괴 애니메이션 |

### 손상 시각 디테일

- **찰과상 (light)**: 차체에 가는 회색 선 1개 (`0x555555`, 알파 0.5)
- **손상 마크 (damaged/critical)**: 여러 개의 긁힌 자국 + 어두운 색조 블렌딩
- **불꽃 (critical)**: 포탑 위에 주황 불꽃(`0xff6600`) + 검은 연기(`0x333333`)
- **파괴 (destroyed)**: 전체 회색화 + 폭발 파티클 + 잔해 이펙트

## 5. 애니메이션 3종

### 대기 애니메이션 (Idle)

모든 탱크 공통으로 **미세한 바운스**(1200ms 주기, 2px 상하 이동, Sine.easeInOut)가 적용된다.

| 탱크 | 고유 대기 동작 |
|------|----------------|
| 캐논 | 공통 바운스만 (안정적) |
| 호버 | 좌우 1.5px 흔들림 (800ms) -- 떠있는 느낌 |
| 중전차 | 좌우 0.5px 진동 (200ms) -- 엔진 진동 |
| 미사일 | 공통 바운스만 (차분) |
| 레이저 | 포신 알파 맥동 (0.85~1.0, 1000ms) -- 에너지 충전 |
| 카타펄트 | 포신 좌우 1px 흔들림 (1500ms) -- 바람에 흔들리는 나무 |

### 발사 애니메이션 (Fire)

1. **머즐 플래시**: 포구 위치에 스타일별 불꽃 표시 후 페이드아웃 (150ms)
2. **차체 반동**: 발사 방향 반대로 밀림 후 복귀
3. **화면 흔들림**: 강도에 따른 카메라 셰이크

| 탱크 | 머즐 플래시 스타일 |
|------|---------------------|
| 캐논 | 주황 불꽃 (`0xff8800`) + 노란 코어 (`0xffdd44`) |
| 호버 | 보라 에너지 링 (`0xce93d8`) + 스트로크 (`0xe1bee7`) |
| 중전차 | 거대한 3중 폭발 (주황→노랑→백색) |
| 미사일 | 주황 불꽃 (캐논과 동일) |
| 레이저 | 시안 에너지 버스트 (`0x00ffff`) + 백색 코어 |
| 카타펄트 | 갈색 먼지 구름 (`0x8d6e63`) 3개 |

### 피격 애니메이션 (Hit)

1. **흰색 플래시**: 100ms 동안 전체 바디를 `0xffffff`로 변경
2. **데미지 팝업**: `-{amount}` 빨간 텍스트 상승 후 페이드
3. **바디 흔들림**: 피격 방향으로 흔들림 + 복귀
4. **(파괴 시)**: 폭발 파티클 + 잔해 비산 애니메이션

## 6. 포탄 6종 디자인

각 탱크 스타일은 고유한 포탄 외형을 가진다.

| 탱크 | 포탄 디자인 | 연기 꼬리 색상 |
|------|-------------|----------------|
| 캐논 | 검은 철 구체 + 금속 광택 + 도화선 불꽃 (주황/노란) | `#888888` (회색) |
| 호버 | 보라 삼각 플라즈마볼 + 에너지 핵 + 보라 꼬리 | `#ce93d8` (연보라) |
| 중전차 | 녹색 직사각 철갑탄 + 구리 띠 + 둥근 탄두 | `#666666` (짙은 회색) |
| 미사일 | 네이비 미사일 본체 + 빨간 탄두 + 날개 + 추진 불꽃 | `#ff8a65` (주황) |
| 레이저 | 다중 글로우 에너지 구체 (시안) + 백색 코어 + 렌즈 플레어 | `#80deea` (연시안) |
| 카타펄트 | 갈색 울퉁불퉁 바위 + 이끼 점 + 하이라이트 | `#8d6e63` (갈색) |

### 특수 포탄

| 포탄 | 디자인 |
|------|--------|
| 바운스탄 | 빛나는 오렌지 구체 (`0xffaa00`→`0xffcc00`) + 별 스파크, 반사 시 불꽃 이펙트 |

### 연기 꼬리 (Smoke Trail)

- 최대 16개 파티클
- 프레임당 알파 -0.06 감소, 크기 x1.03 확대
- 탱크별 고유 색상 및 알파 (레이저 0.7, 호버 0.6, 기본 0.45)
