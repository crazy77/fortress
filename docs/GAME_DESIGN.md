# Fortress - 게임 디자인 문서

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| **장르** | 턴제 포병 전략 게임 (Artillery Strategy) |
| **플랫폼** | 웹 브라우저 (데스크톱/모바일, Phaser 4 RC + TypeScript) |
| **플레이어** | 1v1 (로컬 대전 / vs AI) |
| **핵심 루프** | 탱크 선택 -> 맵 배치 -> [조준 -> 발사 -> 피해 판정 -> 아이템 수집] 반복 -> 승패 |
| **월드 크기** | 2400 x 720 (뷰포트 1280 x 720, 카메라 스크롤) |
| **기본 HP** | 100 |
| **턴 제한** | 15초 |

### 핵심 메카닉

- **시대 상성**: 고전/현대/미래 3개 시대, 가위바위보식 1.2x / 0.85x 데미지 배율
- **분노 시스템**: HP 30% 이하 시 데미지 1.3배 (RAGE)
- **매복 보너스**: 고도차 60px 이상 시 데미지 1.15배
- **라운드 업그레이드**: 승리 시 다음 라운드 데미지 +5% (최대 +25%)
- **콤보 더블턴**: 3연속 명중 시 추가 턴

---

## 2. 턴 구조

```
INTRO -> AIMING -> FLIGHT -> IMPACT -> CLEANUP -> GAME_OVER
  |         |         |         |         |           |
  |    조준/이동/  포탄 비행   착탄/폭발  지형 정리    승패
  |    아이템 사용  궤적 추적   데미지 판정 아이템 드롭  결산
  맵 소개                      특수 효과   낙하 체크
```

| 단계 | 설명 |
|------|------|
| **INTRO** | 맵 소개, 카메라 패닝, 턴 전환 애니메이션 |
| **AIMING** | 조준각/파워 조절, 이동(연료 소모), 무기 선택, 아이템 사용 |
| **FLIGHT** | 포탄 비행 (중력 + 바람 물리), 카메라 추적, 최대 450프레임 |
| **IMPACT** | 직격/스플래시 데미지 판정, 지형 파괴, 특수 효과 (나팔름/드릴/집속) |
| **CLEANUP** | 지형 위 오브젝트 낙하 처리, 아이템 드롭 (20% 확률), HP 체크 |
| **GAME_OVER** | 승패 판정, XP 부여, 업적 체크, 계급 갱신 |
