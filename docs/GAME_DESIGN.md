# Fortress 게임 디자인 문서

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 턴제 포병 전략 (Artillery Strategy) |
| 플랫폼 | 웹 브라우저 (데스크탑/모바일) |
| 엔진 | Phaser 4 RC + TypeScript |
| 핵심 루프 | 탱크 선택 → 맵 배치 → 조준/이동 → 발사 → 피해 판정 → 아이템 수집 → 턴 교대 |
| 플레이어 수 | 2인 (로컬 PvP 또는 vs AI) |
| 기본 HP | 100 |
| 턴 제한시간 | 15초 |

### 핵심 메카닉

- **시대 상성 시스템**: 고전/현대/미래 3개 시대 간 가위바위보 데미지 배율
- **6종 탱크**: 각기 다른 화력/이동성/특수능력 트레이드오프
- **8종 무기**: 기본 무한탄 + 7종 특수탄 (탄약 제한)
- **11종 아이템**: 공격 버프, 방어/회복, 유틸리티, 디버프
- **10종 맵**: 고유 중력/바람/두께 특성
- **프로시저럴 지형**: 매 게임 랜덤 생성, 폭발로 파괴 가능
- **계급 시스템**: 15단계 계급 (XP 기반)
- **업적 시스템**: 18종 업적 (4단계 희귀도)

## 2. 턴 구조

```
INTRO → AIMING → FLIGHT → IMPACT → CLEANUP → GAME_OVER
```

| 페이즈 | 설명 | 플레이어 입력 |
|--------|------|---------------|
| **INTRO** | 턴 시작 연출, 카메라 이동, 턴 마커 표시 | 없음 |
| **AIMING** | 탱크 이동(연료 소모), 각도/파워 조절, 무기 선택, 아이템 사용 | 방향키, 스페이스바 |
| **FLIGHT** | 포탄 비행, 바람/중력 적용, 카메라 추적 | 없음 |
| **IMPACT** | 착탄 판정, 데미지 계산, 지형 파괴, 폭발 이펙트 | 없음 |
| **CLEANUP** | 아이템 드롭, 낙하 체크, 턴 교대 판정 | 없음 |
| **GAME_OVER** | 승패 판정, 업적 체크, XP 부여, 결과 화면 | 확인 |
