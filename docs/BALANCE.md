# Fortress 밸런싱 문서

## 1. 밸런싱 철학

> **DPS(직격+스플래시 기대치) x 이동성 x 특수능력 = 일정**

모든 탱크는 명확한 정체성과 트레이드오프를 가진다.
강한 부분이 있으면 반드시 약한 부분이 존재하며, 어떤 탱크도 모든 상황에서 최적이 되어서는 안 된다.

### 밸런스 3축

| 축 | 설명 | 최강 탱크 | 최약 탱크 |
|----|------|-----------|-----------|
| 화력 (DPS) | 직격+스플래시 기대치 | 중전차 (55+28) | 카타펄트 (22+22) |
| 이동성 | 연료 + 사거리 | 호버 (300연료, 1.15x) | 중전차 (60연료, 0.75x) |
| 특수능력 | 바람저항, 범위, 고유 메카닉 | 레이저 (95% 바람무시) | 캐논 (특수 없음) |

## 3. 시대 상성 매트릭스

3개 시대 간 순환 상성 (가위바위보):

```
고전 (classic) → 미래 (future) 에 강함 (1.2x)
현대 (modern)  → 고전 (classic) 에 강함 (1.2x)
미래 (future)  → 현대 (modern)  에 강함 (1.2x)
```

| 공격자 \ 방어자 | 고전 (캐논, 카타펄트) | 현대 (중전차, 미사일) | 미래 (호버, 레이저) |
|----------------|----------------------|----------------------|---------------------|
| **고전** | 1.0x | 0.85x | **1.2x** |
| **현대** | **1.2x** | 1.0x | 0.85x |
| **미래** | 0.85x | **1.2x** | 1.0x |

### 상성 영향 분석

- **유리 상성 (1.2x)**: 모든 데미지에 20% 보너스. 2~3발 빠른 킬 가능
- **불리 상성 (0.85x)**: 모든 데미지에 15% 감소. 체감상 1~2발 더 필요
- **동일 시대 (1.0x)**: 순수 실력 + 지형 활용 승부

## 4. 데미지 파이프라인

포탄이 착탄하면 다음 순서로 데미지가 계산된다:

```
기본 데미지
  → 시대 상성 배율 (0.85x / 1.0x / 1.2x)
  → 고도 보너스 (높이차 60px 이상 시 1.15x)
  → 분노 배율 (HP 30% 이하 시 1.3x)
  → 매복 배율 (첫 타격 보너스 1.1x)
  → 라운드 업그레이드 (승리당 +5%, 최대 +25%)
  → 쉴드 감소 (보호막 사용 시 0.6x = 60% 감소)
```

### 데미지 계산 상수

| 단계 | 조건 | 배율 | CONFIG 키 |
|------|------|------|-----------|
| 시대 상성 | 항상 적용 | 0.85x / 1.0x / 1.2x | `getEraMultiplier()` |
| 고도 보너스 | 공격자가 60px 이상 높을 때 | 1.15x | `ALTITUDE_BONUS_THRESHOLD: 60` / `ALTITUDE_BONUS_MULTIPLIER: 1.15` |
| 분노 (Rage) | HP <= 30% | 1.3x | `RAGE_HP_THRESHOLD: 0.3` / `RAGE_DAMAGE_MULTIPLIER: 1.3` |
| 매복 (Ambush) | 첫 타격 | 1.1x | `AMBUSH_DAMAGE_MULTIPLIER: 1.1` |
| 라운드 업그레이드 | 연승 시 누적 | 1.0x ~ 1.25x | `ROUND_UPGRADE_PER_WIN: 0.05` / `ROUND_UPGRADE_CAP: 0.25` |
| 쉴드 | 보호막 아이템 사용 시 | 0.6x (60% 감소) | `SHIELD_REDUCTION: 0.6` |

### 최대 데미지 시나리오

중전차 직격 + 모든 배율 적용:
```
55 x 1.2 x 1.15 x 1.3 x 1.1 x 1.25 x 1.0 = ~137 데미지
```

## 6. 아이템 드롭 가중치

아이템은 폭발 후 20% 확률 (`POWERUP_DROP_CHANCE: 0.2`)로 드롭된다.

| 아이템 | 가중치 | 확률 (%) | 분류 |
|--------|--------|----------|------|
| 체력 회복 | 18 | 17.0% | 방어 |
| 보호막 | 14 | 13.2% | 방어 |
| 파워 UP | 10 | 9.4% | 공격 |
| 데미지 UP | 9 | 8.5% | 공격 |
| 이동 UP | 10 | 9.4% | 유틸 |
| 더블 샷 | 8 | 7.5% | 공격 |
| 화염탄 | 8 | 7.5% | 공격 |
| 각도 고정 | 8 | 7.5% | 디버프 |
| 이동 봉쇄 | 8 | 7.5% | 디버프 |
| 바람 반전 | 7 | 6.6% | 유틸 |
| 텔레포트 | 6 | 5.7% | 유틸 |
| **합계** | **106** | **~100%** | |

### 드롭 분류별 비중

| 분류 | 합산 가중치 | 합산 확률 |
|------|------------|-----------|
| 공격 버프 | 35 | 33.0% |
| 방어/회복 | 32 | 30.2% |
| 유틸리티 | 23 | 21.7% |
| 디버프 | 16 | 15.1% |

### 인벤토리 제한

- 최대 4슬롯
- 인벤토리가 가득 차면 필드 아이템 수집 불가
- 디버프 아이템은 사용 시 턴이 소모됨 (공격 불가)

## 7. 맵별 탱크 상성

| 맵 | 최적 탱크 | 이유 |
|----|-----------|------|
| 초원 | 캐논 | 균형 지형, 올라운더 유리 |
| 협곡 | 바운스/드릴 사용자 | 수직 벽면 반사, 지형 관통 |
| 군도 | 미사일 | 섬 간 장거리 사격 필수 |
| 계단 | 호버 | 고저차 이동에 높은 연료 필요 |
| 산악 | 레이저 | 강풍(1.8x) 환경에서 바람 무시 |
| 요새 | 중전차 | 두꺼운 성벽 = 높은 화력 필요, 약풍(0.3x) |
| 사막 | 레이저 | 강풍(1.8x) + 저중력 = 정밀 사격 유리 |
| 화산 | 중전차 | 고중력(1.3x) + 약풍(0.7x) = 화력전 |
| 다리 | 카타펄트 | 얇은 다리 파괴에 넓은 범위 유효 |
| 메사 | 미사일 | 고원 간 장거리 저격 |
